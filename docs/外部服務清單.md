# 外部服務清單（駿斯小助理）

> 最後更新：2026-05-19

---

## 一、對外呼叫的外部服務

| 服務 | 用途 | 呼叫方式 | 金鑰/憑證 | 備註 |
|------|------|----------|-----------|------|
| **LINE Messaging API** | 發送訊息（reply / push）、查詢用戶資訊、查詢群組資訊 | `@line/bot-sdk` SDK | `CHANNEL_ACCESS_TOKEN`（Bearer）| webhook 簽章驗證用 `CHANNEL_SECRET` |
| **OpenAI API** | 任務萃取、勵志語、水質分析、AI 智能客服（ai-agent） | `openai` SDK | `OPENAI_API_KEY` | 模型 `gpt-4o-mini`；使用 chat completions |
| **Google Gemini REST API** | 公告分類（5 層管線 Pass 2） | `fetch` 直接呼叫 `generativelanguage.googleapis.com` | `GEMINI_API_KEY` | 預設模型 `gemini-2.5-flash-lite`；可用 `ANNOUNCEMENT_CLASSIFIER_MODEL` 覆蓋 |
| **中央氣象署開放資料平台（CWA）** | 風力預報（竹科高爾夫）、天氣資訊、UV 指數 | `fetch` | `CWA_API_KEY`（Authorization header）| `opendata.cwa.gov.tw/api/v1/rest/datastore/…` |
| **Ragic（ap7.ragic.com）** | 員工資料查詢（面試模組）、慎用名單查詢 | `fetch` | `RAGIC_API_KEY`（普通查詢）、`RAGIC_CAUTION_API_KEY`（慎用名單）、`RAGIC_DOMAIN`、`RAGIC_DATABASE_ID`、`RAGIC_USERNAME` | |
| **體育署救生員查詢（isports.sa.gov.tw）** | 救生員證照資格查詢 | Node.js `https` + `cheerio` 網頁爬取 | 無 token（公開查詢） | SSL 證書鏈不完整，使用 `rejectUnauthorized: false` 繞過；如有疑慮可改更新 CA bundle |
| **Google Apps Script（客滿調查）** | 接收 SurveyCake 滿意度問卷資料 | Google Apps Script → 推送 `POST /api/survey-webhook` | `SURVEY_WEBHOOK_TOKEN`（本系統驗證用） | 使用 `onSheetChange` trigger |
| **外部儀表板 webhook**（選配） | 推送服務健康快照（T003 新增） | `fetch` POST | `DASHBOARD_WEBHOOK_URL`、`DASHBOARD_WEBHOOK_SECRET`（HMAC-SHA256 簽名） | 空白則停用；簽名 header: `X-Hub-Signature-256` |

## 四、外部服務容錯設計

| 服務 | 容錯策略 |
|------|----------|
| LINE API | 失敗記錄到 `outgoing_messages`，status='failed'，不影響 webhook 處理 |
| OpenAI API | try/catch，失敗回傳空結果或略過 AI 功能；429 錯誤時主動切換到 Gemini |
| Gemini API | AbortController 8 秒 timeout；失敗 log + pipeline stats 記錄 |
| CWA API | fetch timeout 10 秒；失敗時回傳「氣象資料暫時無法取得」 |
| Ragic | Promise.all 並行查詢，各自獨立 try/catch；失敗時查詢結果顯示錯誤訊息 |
| 體育署救生員 | try/catch；SSL `rejectUnauthorized: false`；超時 fallback 提示無法查詢 |
| 公告白名單（DB） | DB 查詢失敗時 fallback 到 `announcementConfig.ts` 的 `VIP_USERS` 常數（T003） |
| Dashboard Webhook | fetch timeout 8 秒；失敗時寫入 `service_health_snapshots`（webhookStatus='error:...'），不影響主流程（T003） |
